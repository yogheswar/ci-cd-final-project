
# CI/CD Final Project

## Project Overview
This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions, Tekton, and Red Hat OpenShift.

## Technologies Used
- GitHub
- GitHub Actions
- Python
- Flake8
- Nose
- Tekton
- Kubernetes
- Red Hat OpenShift

## Project Objectives
- Automate code quality checks using GitHub Actions.
- Execute unit tests using Nose.
- Create Tekton tasks for cleanup and testing.
- Deploy the application using OpenShift Pipelines.
- Verify successful pipeline execution and application logs.
